# A Little Universe for Vale

## Vision
A beautiful, interactive, personalized birthday website for Valerie (aka Vale). The website is conceived as "A Little Universe Made Just for Vale", unfolding progressively through seven thoughtful scenes with dreamlike editorial elegance, vintage scrapbook charm, interactive 3D elements, and celebratory surprises.

## Core Milestones
- **Phase 1: Foundation & Asset Pipeline** — Setup Vite, React 19, Tailwind CSS v4, custom fonts, color system, and asset loading for `image 1.png`, `image 2.png`, `image 3.png`.
- **Phase 2: Scene Implementation (Scenes 01 - 07)** — Implement Invitation portal, Editorial introduction, Digital scrapbook with Lightbox, Appreciation flip cards, Handcrafted letter, 3D interactive surprise box, and Final celebration with interactive birthday cake & confetti.
- **Phase 3: Ambient Audio & Sensory Polish** — Implement Web Audio API procedural soundscape, celestial starfield canvas, smooth scrolling, and mobile responsive validation.
