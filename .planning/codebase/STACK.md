# Technology Stack

## Core Technologies
- **Runtime & Language**: Node.js v22+, TypeScript 5.8+ / 7.0 (Strict mode)
- **Framework**: React 19 (`react` ^19.3.1, `react-dom` ^19.3.1)
- **Bundler & Dev Server**: Vite 8 (`vite` ^8.3.5) with `@vitejs/plugin-react` and `@rolldown/plugin-babel`
- **Styling**: Tailwind CSS v4 (`tailwindcss`, `@tailwindcss/vite`) with custom luxury palette variables and modern CSS
- **Animation**: Framer Motion (`framer-motion` ^12.4.0) for fluid transitions, staggered typography, 3D card flips, and gift box interactions
- **Icons**: Lucide React (`lucide-react` ^1.16.0)
- **Celebration Effects**: Canvas Confetti (`canvas-confetti`, `@types/canvas-confetti`)
- **Audio Experience**: Interactive Web Audio API procedural celestial soundscape with custom audio toggle
- **Typography**: Google Fonts — Cormorant Garamond / Playfair Display (editorial serif), DM Sans / Plus Jakarta Sans (clean body), Caveat (intimate handwritten annotations)
